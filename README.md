# Pi-telemetry-platform

## Problem 
I want to collect raspberry pi telemetry from my raspberry pi 5 in order to automatically monitor and analyze system performance behavior and health over time.

## intial Goal 
I would like to create a dashboard that visulizes important raspberry pi system metrics and make it easy to understand current and historical system health.

## Architecture
 Raspberry pi -> Telemetry Collector -> stdout

## Current Status
Finished script for collecting system snapshot. Working on docker currently
